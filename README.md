# E-Commerce Sales Analysis

## 📊 Project Overview

This project analyzes e-commerce sales data to identify sales trends, top-performing products, category performance, and business opportunities.

## 🎯 Objectives

- Analyze total sales and profit
- Identify the best-selling product
- Compare category performance
- Analyze monthly sales trends
- Generate business insights from the data

## 🛠️ Tools Used

- Python
- Pandas
- Matplotlib
- Google Colab
- GitHub

## 📈 Key Results

- Total Sales: ₹802,000
- Total Profit: ₹139,500
- Total Quantity Sold: 83
- Best-Selling Product: Laptop
- Highest-Sales Category: Electronics
- Highest-Sales Month: April 2026

## 🔍 Analysis Process

1. Created the dataset
2. Checked missing values and duplicates
3. Calculated sales and profit
4. Analyzed product performance
5. Analyzed category performance
6. Studied monthly sales trends
7. Created visualizations
8. Extracted business insights

## 💡 Key Insights

The analysis shows that Electronics generated the highest sales, with Laptops being the strongest-performing product. April recorded the highest monthly sales.
